# Lakshya 🎓

Lakshya is a professional India-first study platform for web and mobile/PWA use.

## Product direction
- Class 6–12 learning foundation
- NCERT + Indian board-friendly structure
- JEE / NEET practice architecture
- Hindi + English experience
- AI Study Assistant, AI quizzes and AI-powered revision
- Study planner, focus timer, notes, analytics, goals and streaks
- Responsive PWA designed for Android-first usage and slower networks

## Stack
- Next.js App Router + TypeScript
- Responsive CSS UI
- PWA-ready manifest
- Firebase planned for authentication, Firestore and file storage
- AI layer planned behind secure server-side APIs

## Development roadmap
1. Professional responsive shell and dashboard
2. Navigation + subject/chapter system
3. Firebase authentication and student profile
4. Notes/PDF storage and study planner
5. Practice engine and JEE/NEET question system
6. AI study assistant and AI quiz generation
7. Analytics, goals, streaks and notifications
8. Admin/content management
9. Offline/PWA polish and Android packaging

## Quality principles
Performance, accessibility, mobile usability, secure API boundaries, educational accuracy, and maintainable code are treated as first-class requirements.

## Deployment
Vercel production deployment is connected to the main branch.
