# Lakshya 🎓

A professional study platform designed for web and mobile-friendly use.

## Vision
Lakshya brings study planning, focused learning, revision, practice, progress tracking, and productivity into one clean experience.

## Planned modules
- Dashboard
- Study planner
- Subjects & chapters
- Focus timer
- Notes
- Quizzes & practice
- Progress analytics
- Goals & streaks
- Settings

## Web + App
The project is designed as a responsive web application/PWA so the same codebase can provide a polished desktop, tablet, and mobile experience.
